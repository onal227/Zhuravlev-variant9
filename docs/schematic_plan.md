# План разводки для EasyEDA

## Соединения

| Источник | Вывод источника | Arduino Uno | Назначение |
|---|---|---|---|
| LDR | AO | A0 | Освещенность |
| LDR | VCC | 5V | Питание |
| LDR | GND | GND | Общий провод |
| NTC | OUT | A1 | Температура |
| NTC | VCC | 5V | Питание |
| NTC | GND | GND | Общий провод |
| POT | SIG | A2 | Заряд батареи |
| POT | VCC | 5V | Питание |
| POT | GND | GND | Общий провод |
| Relay | IN | D8 | Управление светильником |
| Relay | VCC | 5V | Питание |
| Relay | GND | GND | Общий провод |
| LED | анод через 100 Ом | D9 | Индикация темноты |
| LED | катод | GND | Общий провод |

## Что проверить перед экспортом

1. Все три датчика подключены к аналоговым входам.
2. У реле и датчиков есть общий GND.
3. У светодиода есть последовательный резистор 100 Ом.
4. На схеме подписаны A0, A1, A2, D8, D9 и номинал резистора.
5. Названия элементов совпадают с таблицей компонентов.
