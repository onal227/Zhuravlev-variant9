# Краткий текст для защиты

Мой курсовой проект - виртуальная система уличного освещения на Arduino Uno, вариант 9. Она использует LDR для измерения освещенности, NTC для температуры и потенциометр для моделирования напряжения батареи. Опрос происходит один раз в секунду.

Если освещенность меньше 20 процентов, Arduino включает реле светильника и синий светодиод. При переходе в это состояние печатается событие THRESHOLD. После возвращения освещенности к норме печатается событие NORMAL.

Строки Serial Monitor имеют простой формат DATA и EVENT, поэтому Node-RED может разобрать их без сложного парсера. Node-RED формирует SQL-файл, проверяет диапазоны датчиков и записывает показания в таблицу readings, а события - в таблицу events.

Для неисправности я использую значение s1=120, которое выходит за диапазон 0..100 процентов. В таком случае flow записывает событие FAULT с указанием датчика.

Основные расчеты: для синего светодиода выбран резистор 100 Ом; шаг LDR составляет примерно 0,098 процента; при периоде 1 секунда объем данных равен примерно 10,368 МБ в сутки.
