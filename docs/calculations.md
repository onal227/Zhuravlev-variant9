# Расчеты для варианта 9

## 1. Резистор светодиода

Синий светодиод имеет прямое напряжение Uf = 3,0 В, ток I = 20 мА = 0,02 А.

R = (5 - Uf) / I = (5 - 3,0) / 0,02 = 100 Ом.

Выбираем стандартный резистор 100 Ом.

## 2. Шаг АЦП

Шаг по входному напряжению Arduino Uno:

ΔU = 5 / 1024 = 4,88 мВ.

Для LDR: 100 / 1023 = 0,0978 %, примерно 0,098 % на отсчет.

Для NTC при диапазоне -20..80 °C: 100 / 1023 = 0,0978 °C на отсчет.

Для потенциометра 0..14 В: 14 / 1023 = 0,0137 В на отсчет, или 13,7 мВ.

## 3. Объем данных

T = 1 с, поэтому число записей за сутки:

N = 86400 / 1 * 3 = 259200 записей.

V = 259200 * 40 = 10368000 байт = 10,368 МБ в сутки.

За 30 суток: 10368000 * 30 = 311040000 байт = 311,04 МБ.
