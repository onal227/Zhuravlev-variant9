# Вариант 9 - Уличное освещение

Учебный виртуальный проект Arduino Uno, Wokwi, EasyEDA, Node-RED и SQLite. Проект предназначен для моделирования системы уличного освещения и учета показаний датчиков.

## Параметры

- LDR: освещенность 0-100 %, аналоговый вход A0.
- NTC: температура -20-80 °C, аналоговый вход A1.
- POT: напряжение батареи 0-14 В, аналоговый вход A2.
- Реле светильника: D8.
- Синий LED: D9 через резистор 100 Ом.
- Период опроса: 1 секунда.
- Событие: освещенность ниже 20 %.

## Wokwi

[Открыть проект Wokwi](https://wokwi.com/projects/479052795969392641)

Файлы `sim/diagram.json` и `firmware/variant9.ino` используются вместе в одном проекте Wokwi.

## Состав

- `sim/` - схема Wokwi.
- `firmware/` - прошивка Arduino.
- `db/` - SQLite, схема базы, запросы и SQL-загрузка.
- `data/` - нормальный журнал и журнал с ошибочными значениями.
- `nodered/` - flow Node-RED для разбора журнала и загрузки SQLite.
- `docs/` - схемы, BOM, диаграммы, пояснительная записка, инструкция и результаты проверок.

Основные файлы:

- `firmware/variant9.ino` - прошивка Arduino.
- `sim/diagram.json` - описание схемы Wokwi.
- `nodered/flow.json` - поток Node-RED.
- `db/schema.sql` - структура базы данных.
- `db/queries.sql` - контрольные запросы.
- `docs/schematic.pdf` - экспорт принципиальной схемы EasyEDA.
- `docs/bom.csv` - перечень компонентов EasyEDA.
- `docs/Курсовая_пояснительная_записка.docx` - пояснительная записка.
- `docs/Инструкция пользователя.docx` - инструкция запуска и проверки.

## Состояние

Основной сценарий проверен в Wokwi, Node-RED и SQLite. Нормальный журнал содержит 39 показаний и 4 события: два `THRESHOLD` и два `NORMAL`. Для ошибочных значений подготовлен отдельный журнал с проверкой диапазонов.

Принципиальная схема EasyEDA, BOM, исходный код, схема Wokwi, flow Node-RED и итоговые документы находятся в репозитории. Перед печатью пояснительной записки необходимо просмотреть DOCX в Word и сверить диапазон NTC с формулировкой задания.
