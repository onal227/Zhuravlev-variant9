# Курсовой проект Вариант 9

Система виртуального сбора и учета данных для уличного освещения на Arduino Uno.

## Параметры варианта

- LDR: освещенность 0..100 %, аналоговый вход A0.
- NTC: температура -20..80 °C, аналоговый вход A1.
- POT: заряд батареи 0..14 В, аналоговый вход A2.
- Реле светильника: D8.
- Синий светодиод: D9, резистор 100 Ом.
- Опрос: 1 раз в секунду.
- Событие: освещенность ниже 20 %.

## Файлы

- `firmware/variant9.ino` - прошивка Arduino.
- `sim/diagram.json` - схема Wokwi.
- `db/schema.sql` - структура базы.
- `db/queries.sql` - три контрольных запроса.
- `db/load.sql` - пример загрузки.
- `nodered/flow.json` - flow Node-RED.
- `data/log.txt` - пример нормального лога.
- `data/log_fault.txt` - пример неисправности.
- `docs/calculations.md` - расчеты.
- `docs/components.csv` - перечень компонентов.

## Запуск

1. Импортировать `sim/diagram.json` в новый проект Wokwi.
2. Открыть `firmware/variant9.ino` в Wokwi и запустить симуляцию.
3. Скопировать Serial Monitor в `data/log.txt`.
4. Запустить `start-nodered.bat` из корня проекта.
5. Открыть `http://localhost:1880` и импортировать `nodered/flow.json`.
6. Проверить пути `data/log.txt`, `db/load.sql` и `db/variant.db`.
7. Нажать `Deploy`, затем кнопку `Загрузить вручную`.
8. Проверить базу командами:

```text
sqlite3 db/variant.db ".read db/queries.sql"
```

## Проверка FAULT

Временно используй `data/log_fault.txt` вместо `data/log.txt` и запусти загрузку вручную. Для значения `s1=120` должна появиться запись `FAULT` с текстом `датчик s1 вне диапазона`.
